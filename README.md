# Spread Monitor

Telegram Mini App scaffold for @Cifraspredbot.

Public source repository. Never commit bot tokens or API secrets.

Demo only until verified Cifra Market order-book and Rapira RUB→USDT exchange quotes are integrated. The app will not send trading alerts without verified quote feeds.

Configure BOT_TOKEN, ALLOWED_TELEGRAM_IDS, WEBHOOK_SECRET, PUBLIC_URL as Render environment secrets.
